| 行 | 左列 | 值 | 右列 | 值 |

| 1 | Xa | 659.232 | Ya | 355.537 |
| 2 | Xb | 406.593 | Yb | 654.051 |

| 4 | tanα | 2.630329 | tanβ | 1.712038 |
| 5 | tanα·tanβ | 4.503222 | tanα+tanβ | 4.342367 |
| 6 | Xa·tanα | 1733.997 | Ya·tanα | 935.179 |

公式（与上表逐格对应）：

```
tanα = tan(α),  tanβ = tan(β)
Xp = (Xa·tanα + Xb·tanβ + (Yb−Ya)·tanα·tanβ) / (tanα + tanβ)
Yp = (Ya·tanα + Yb·tanβ + (Xa−Xb)·tanα·tanβ) / (tanα + tanβ)
```

注意 `core.forwardIntersection()` 现有余切式与此**等价**（乘 tanα·tanβ 即得上式），数值实测 Xp=869.198、Yp=735.228，无需改算法；要补的是**表格数据模型**（上面 18 个格子）。

## 2. 闭合导线（教材例：右角，顺时针）

已知：A(536.27, 328.74)，起始方位角 α_A1 = 48°43′18″
右角：β1=97°03′00″、β2=105°17′06″、β3=101°46′24″、β4=123°30′06″、βA=112°22′24″
边长：D_A1=115.10、D_12=100.09、D_23=108.32、D_34=94.38、D_4A=67.58

关键事实：**Σβ右 = 539°59′00″ ≈ 540° = (n−2)·180°**（n=5）。
即：顺时针导线量右角时，右角就是内角；只有**逆时针**导线量右角才是 (n+2)·180°。

所以 `expectedAngleSum(closed: true, leftAngles: false)` 写死 (n+2)·180 是**错的**，必须按实测角和的接近者判定（内角和/外角和），并把判定结果暴露给界面提示。

## 3. 极坐标法放样（第七章练习题）

已知：J(502.110, 496.225)、K(746.202, 456.588)，设计点 P(450.000, 560.000)。
在 J 点设站、后视 K，求放样 β 与 D：

| 量 | 值 |
| --- | --- |
| α_JK | 350°46′35.4″ |
| α_JP | 129°15′07.1″ |
| **β = (α_JP − α_JK) mod 360** | **138°28′31.6″**（与教材答案一致） |
| D = |JP| | 82.357 m |

约定：β 是**由后视方向顺时针转到前视方向**的角，范围 [0,360)。

## 4. 象限角与方位角（§4.4）

R 为从标准方向北端或南端起、顺时针或逆时针到该直线的**锐角**：

| 象限 | 关系 | 方位角范围 |
| --- | --- | --- |
| Ⅰ（北东） | R = α | 0°–90° |
| Ⅱ（南东） | R = 180° − α | 90°–180° |
| Ⅲ（南西） | R = α − 180° | 180°–270° |
| Ⅳ（北西） | R = 360° − α | 270°–360° |

显示习惯：`α=123°45′30″ → R=56°14′30″ 南东`。

## 5. 四等水准双面尺记录（实验三）

每站：后尺上丝/下丝、前尺上丝/下丝 → 后距/前距（= |上丝−下丝|×100）、视距差 d=后距−前距、Σd；
中丝黑面/红面读数 → K+黑−红（K=4687 或 4787，检核 |差值| ≤ 3mm）、高差中数 = [(黑后−黑前)+(红后−红前)±100]/2。
